📖 **New on ANYFREEBOOK**

Four things went live this week, and one of them is a bug fix you may have hit.

**Anyone can now join an institution.** One click, no invite needed. Joining never changes an existing role, so it can't demote an owner — and the RLS policy that used to allow a self-join with *any* role (including `owner`) has been tightened. That was a real hole: any signed-in user could have taken over an institution. It's closed.

**Your classroom keeps its history.** Every live session is recorded — how long it ran, how many people attended, and who was there. Signed-in attendees show by name; anonymous ones show by a stable guest id, so a returning visitor is still recognisable. You can now see how much time each attendee spent in the class.

**Every published book can be downloaded.** EPUB and plain text, from a real download button on the reading page. If a book was published as an attached file, you get that exact file.

**Publishers can upload a cover image** when they publish.

**And the app stopped showing "Application error: a client-side exception has occurred."** Three real causes, all fixed: the same ad slot being pushed to AdSense twice, a PDF page being rendered onto one canvas by two handlers at once, and a login cookie being written to the browser in two chunks of which only the second arrived.

There's also a new **What's new** page and a **sources** page that explains every open-access library behind the catalogue, what it holds, and what a result from it actually means.
